## Direction and implementation

User selected Anti-slop during mode for this conversation. No global setting was
written. ENERGY 2 / RHYTHM 2 / MOTION 1. The merchant's task is to find a product,
compare its price/stock/publication state and edit or apply a deliberate operation.
The existing graphite sidebar, warm canvas, Urbanist, thin borders and controlled
orange remain. Actual product photos provide identity when present; missing photos
retain the existing honest Package placeholder.

The four real store totals become compact scope filters. Search, native sorting,
filter disclosure, refresh and ranking remain together. Applied filters have
individual removal. Selection reveals bulk controls. Edit is visible; existing
secondary operations use a native disclosure. Mobile retains all product facts.
Controller prefix is byte-identical after the four exact reviewed import additions.
No request, authority, version, mutation, ranking, pricing, pagination or export
logic was changed. The function inventory is in the companion plan.
