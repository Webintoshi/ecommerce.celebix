# Akbank VPS-1123 Recognition Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Validate current Akbank credentials when an authenticated inquiry returns the documented VPS-1123 not-found result, then activate Ezmeo through the normal worker.

**Architecture:** Extend the existing exact not-found classification. Preserve raw response authentication, terminal identity, empty-result requirements and all paid-settlement gates. Admit the reviewed source closure with its own execution digest, publish all six compatible readers and replace only the matching Akbank LIVE authority digest after all readers are accepted.

**Tech Stack:** TypeScript, Node.js 24, PostgreSQL 16, existing hosted-payment workers and canonical Coolify release tools.

**Spec:** `docs/superpowers/specs/2026-10-25-akbank-hosted-pos-design.md`; official Akbank document asset `https://sanalpos.akbank.com/460.02e19c63.chunk.js`, error table VPS-1123.

## Global Constraints

- Never collect card numbers/CVV, create a bank credential or submit a charge/refund.
- No schema/function changes; native278/full2062 remains unchanged.
- Preserve all merchant records, orders, tariff snapshots, PayTR/iyzico authorities, existing secrets and worker modes.
- Only the user-authorized current Ezmeo credentials replace its old pending configuration.
- Cemo is the sole publisher; use fresh baseline, exclusive canonical lock, exact source and official signup/build gates.
- Do not reuse previous release receipts or claim a real card/3DS payment occurred.

## Review Focus

- Missing or invalid HMAC must not validate credentials or settle payment.
- Wrong merchant/terminal or inquiry transaction code must remain unavailable.
- A nonempty or malformed transaction list must not count as an empty not-found result.
- A signed not-found inquiry must remain unpaid/pending in payment status handling.
- Mixed rollout must fail closed until the new execution authority matches accepted readers.
