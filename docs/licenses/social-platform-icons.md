# Social platform icons

The manual sales platform selector embeds the Instagram, Facebook, X,
Pinterest, TikTok and WhatsApp SVG paths from Simple Icons 13.21.0.
Paths use `currentColor`; icons are decorative beside visible platform labels.
No icon package, remote font or runtime network request is required.

Source: https://github.com/simple-icons/simple-icons/tree/13.21.0/icons
