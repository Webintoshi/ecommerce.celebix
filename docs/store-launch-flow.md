# Magaza Acilis Akisi

## Faz 1

1. Owner panel veya CLI ile yeni magaza kaydi acilir
2. `stores/<slug>/store.config.json` olusur
3. Supabase management token varsa yeni Supabase projesi acilir
4. `schema.sql` ve secili runtime migration'lari yeni projeye uygulanir
5. `stores/<slug>/admin.env.local` icine gizli baglanti env'leri yazilir
6. Domain baglanir
7. Deployment baslatilir
