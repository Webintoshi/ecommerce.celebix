# Barcode label price font

Roboto Bold (700), version 3.015, Latin Extended, from Google Fonts.
Only the PDF price field uses it. Roboto regular and medium keep their existing mappings.
The static font is embedded in the server module and subset again by pdfmake when writing a PDF; the admin browser downloads no extra font.
