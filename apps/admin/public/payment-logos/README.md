Bu klasor admin odeme ayarlari ekranlarinda kullanilan provider logolarini tutar.

## Kullanilan kaynaklar

- Temel PNG seti: mevcut Celebix storefront assetleri
- Ek SVG seti: GurmePOS referans varliklari
