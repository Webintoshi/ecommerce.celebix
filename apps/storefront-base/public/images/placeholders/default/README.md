# Default storefront placeholders

The generated storefront uses component-based placeholders from
`components/placeholders/DefaultDemoPlaceholder.tsx` instead of brand-specific
stock imagery. The IDs below are stable so generated stores can replace them
with real assets later without changing layout contracts.

- `placeholder-01`: homepage hero
- `placeholder-02`: hero secondary tile
- `placeholder-03` to `placeholder-06`: category cards
- `placeholder-07` to `placeholder-10`: product cards and PDP fallback
- `placeholder-11`: blog cover fallback
- `placeholder-12`: empty-state fallback
