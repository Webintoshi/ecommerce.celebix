## Sayfa İçi SEO (On-Page SEO) Nedir?

On-page SEO, web sitenizin her bir sayfasının arama motorları için optimize edilmesidir. Off-page SEO (backlink'ler) ve teknik SEO'dan farklı olarak, on-page SEO tamamen sizin kontrolünüzdedir.

2026'da on-page SEO artık sadece keyword stuffing değildir. Google'ın BERT ve MUM algoritmalarıyla birlikte arama niyeti ve içerik kalitesi çok daha belirleyici hale gelmiştir.

## On-Page SEO Bileşenleri

### 1. Anahtar Kelime Araştırması

Doğru anahtar kelimeleri seçmek, başarının yarısıdır.

**Araçlar:**
- Ahrefs / Semrush (ücretli)
- Google Keyword Planner (ücretsiz)
- AnswerThePublic (sorular için)
- Google Search Console (mevcut performans için)

**Strateji:**
- Short-tail (1-2 kelime): yüksek hacim, yüksek rekabet
- Long-tail (3+ kelime): düşük hacim, düşük rekabet
- Question keywords: voice search için kritik

### 2. Başlık Etiketleri (H1-H6)

```html
<!-- Yanlış -->
<h1>Selam</h1>
<h3>Core Web Vitals</h3>

<!-- Doğru -->
<h1>Core Web Vitals Nedir? 2026 Kapsamlı Rehber</h1>
<h2>LCP: Largest Contentful Paint</h2>
<h3>Hedef Değerler</h3>
```

**Kurallar:**
- Sayfada sadece 1 tane H1 olsun
- H1 içinde primary keyword yer alsın
- H2-H6 hiyerarşik olsun
- Heading metinleri açıklayıcı olsun

### 3. Meta Etiketleri

**Title Tag:**
- 50-60 karakter aralığında olsun
- Primary keyword başta yer alsın
- Marka adı sonda bulunabilir
- Her sayfada benzersiz olsun

```text
✓ Core Web Vitals Nedir? 2026 Rehberi | Storefront SEO
✗ 10 SEO Rehberleri - Storefront
```

**Meta Description:**
- 150-160 karakter ideal aralıktır
- CTA içermelidir
- Keyword kullanımı doğal görünmelidir
- Kullanıcıyı tıklamaya ikna etmelidir

```text
✓ Core Web Vitals metriklerini öğrenin. LCP, INP ve CLS nasıl iyileştirilir? Ücretsiz rehberimizi okuyun ve hemen optimize etmeye başlayın.
```

### 4. URL Yapısı

```bash
✓ /seo/teknik-seo/core-web-vitals
✓ /seo/core-web-vitals-nedir

✗ /seo/post?id=12345
✗ /seo/2024/02/19/core-web-vitals-article-v2
```

**Best Practices:**
- Kısa olsun
- Keyword içersin
- Küçük harf ve tire yapısı kullansın
- Mümkün olduğunca statik kalsın

### 5. İçerik Optimizasyonu

**Semantik SEO:**
- LSI keywords kullanın
- Related entities ekleyin
- TF-IDF mantığını dikkate alın

**İçerik Uzunluğu:**
- Pillar sayfası: 2.000-4.000 kelime
- Cluster sayfası: 1.500-3.000 kelime
- Blog yazısı: 1.000-2.000 kelime

## Search Intent (Arama Niyeti)

Her sorgunun bir niyeti vardır. Bunu anlamadan yapılan optimizasyon eksik kalır.

| Niyet | Açıklama | İçerik Türü |
|---|---|---|
| **Informational** | Öğrenmek istiyor | Rehber, how-to, tutorial |
| **Navigational** | Belirli bir siteyi arıyor | Anasayfa, login |
| **Commercial** | Karar aşamasında | Karşılaştırma, review |
| **Transactional** | Satın almak istiyor | Ürün sayfası, checkout |

**Örnek:**
- "seo nedir" → Informational
- "ahrefs login" → Navigational
- "ahrefs vs semrush" → Commercial
- "ahrefs pricing" → Transactional

## On-Page SEO Checklist 2026

- [ ] Title tag unique ve optimize edildi
- [ ] Meta description unique ve CTA içeriyor
- [ ] H1 tek, H2-H6 hiyerarşik
- [ ] URL kısa, keyword'lü ve statik
- [ ] İçerik search intent'e uygun
- [ ] Internal links yeterli
- [ ] External authoritative links var
- [ ] Görsellerde alt text eksiksiz
- [ ] Schema.org JSON-LD eklendi
- [ ] Mobile responsive yapı korundu
- [ ] Page speed iyi durumda
- [ ] İçerik güncel tutuluyor
